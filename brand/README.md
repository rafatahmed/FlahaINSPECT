# FlahaINSPECT marks

Three wordmarks, **transparent PNG** (1254×1254):

| File | Use |
|------|-----|
| `logo-color.png` | Light UI, login, marketing |
| `logo-black.png` | Light print / light chrome |
| `logo-white.png` | Dark chrome (sidebar, splash) |

Do not put these on a white plate. Copies also live in `apps/web/public/brand/` and `apps/mobile/assets/brand/`.
