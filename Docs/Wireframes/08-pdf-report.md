# 08 — PDF report (R2)

**Trigger:** manager, web, `POST /projects/:id/reports` then poll.

```
Page 1
  Flaha Agri Tech · FlahaINSPECT
  Project name · date range · generated by · generated at
  Counts: Defect / Normal / Note · open defects
  Map figure (same category colors)

Pages 2+
  Grid, up to 200 points:
  thumb | time | coords | accuracy | note | remarks | procedure | status | inspector

Footer
  Confidential — Flaha Agri Tech · page n of m
```

## Must have

- Hard cap 200 points; if unfiltered set is larger, API 400 `VALIDATION_ERROR` — UI asks for filters.
- Second generate while queued/processing: show existing job (409 `REPORT_IN_PROGRESS`).
- Missing thumb: cell shows `Image unavailable`, job still succeeds.
- All user text HTML-escaped (KD-40).
- Download via audited BFF URL; manager only.

## Must not have

- Client self-serve generate.
- Promise of camera-original resolution.
- GNSS / HDOP columns in R2.
